Photo se calorie nikalne ke liye Google ki free AI key (Gemini API key) chahiye. Sirf 2 minute ka kaam hai — neeche ke step follow karo.

1Yeh link kholo

Apne Google (Gmail) account se login karo.

aistudio.google.com ↗

2API Keys → Create API key

Left menu mein API Keys kholo (①), phir upar Create API key dabao (②).

3Project chuno → Create key

Project wale box mein koi bhi project chuno (①) — list khaali ho to Create project chuno. Phir Create key dabao (②).

4Copy key dabao

Key ban jayegi (AIza… ya AQ.… se shuru). Neeche Copy key dabao.

5Key yahan paste karo

Neeche box mein key paste karo, ya Paste button dabao. (Baad mein yeh key Settings → AI scan setting mein dikhegi.)
